# Thread: remembering is not verifying

“Has it changed since we spoke?” needs two records: what we actually discussed and what the world shows now. A recent search alone cannot answer it. Thread preserves that distinction through retrieval, generation, and the interface.

**One agent, one tool.** A TypeScript loop supplies relevant history to a model, which answers, clarifies, or calls `web_search`. The tool batches independent Tavily queries; it is the only model-callable capability. Memory retrieval is application code. Transports support OpenAI Responses, AgentRouter Chat Completions, and Gemini without changing the loop. Provider reasoning/continuation state is preserved within a run, not used as permanent memory.

**Originals before summaries.** Node's built-in SQLite stores original turns, source excerpts, timestamps, and run metadata. Retrieval prioritizes an explicit calendar date, recent context, FTS matches, and recent cross-conversation exchanges, within fixed count/character budgets. Dates resolve in the browser timezone, including DST; ambiguity and truncation stay visible. Every query is scoped to a server-issued identity, and demo history is isolated. Failed answers are excluded, but the user's question remains recallable. Missing history calls for clarification, not invention.

**Then is not now.** Saved excerpts are immutable observations. A prior answer is a claim, not truth; retrieval time is not a publication/effective date. The prompt requires fresh official evidence for change questions and equivalent plan, currency, seat, and billing terms. It distinguishes dated changes, different observed values, matching checked values, and insufficient evidence. Search failure cannot mean “unchanged.” Server-assigned citations resolve to retrieved URLs; unknown IDs are removed with a warning. This validates provenance, not semantic entailment. Source injection remains a model-level risk despite explicit trust boundaries and a read-only tool.

**Latency and failure budgets.** Casual conversation uses one model call. Research is capped at three search rounds, twelve queries, four model calls, and 120 seconds. Queries within a batch run concurrently, with 15-second search timeouts. There is no persistent search cache or hidden retry cascade. SSE streams progress and provisional text; only completed final answers become factual memory. Disconnects propagate cancellation, same-owner requests serialize, and UUIDs prevent duplicate paid execution. Token usage and timing are recorded rather than estimated.

**Rejected.** A planner/researcher/critic swarm adds serial latency without measured benefit. Sending all history has unbounded cost. LLM summaries can erase an exact shortlist or price. A vector service adds infrastructure before lexical failures are measured. A separate fetch/browser tool violates the one-tool constraint. The tradeoff is explicit: bounded lexical recall and search excerpts have limits.

**Evidence and another week.** Deterministic temporal scenarios and integration/browser tests check mechanics; separate real-model evaluations screen missing memory, billing mismatch, absent baselines, and injection. These are not frontier-parity benchmarks. Next: compare held-out conversations with a full-history baseline, measure p50/p95 latency and claim-level support, add semantic retrieval only where recall improves, and test targeted verification for high-impact claims. Authentication, retention/encryption, and distributed quotas precede public deployment.
